## עקרונות
- ניהול מלא לפי Agile/Scrum
- סנכרון מלא 100% בין קוד, מסמכים וגרסאות
- עיצוב פשוט ואלגנטי
- תמיכה מלאה בעברית (RTL) + אנגלית + ערבית + רוסית
- Polling (1.5–2 שניות) במקום Real-time מלא
- העברת שיחה ל-Dynamics 365 רק בסוף השיחה
