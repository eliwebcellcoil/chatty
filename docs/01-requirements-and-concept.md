# Chatty – מסמך דרישות וקונספט כללי
**Ver. 0.1.0 | Build 001 | 03.11.2026**

## 1. חזון המוצר
Chatty היא מערכת צ'אט תמיכה מקצועית, פשוטה לתחזוקה ועשירה בפונקציונליות.  
מיועדת לניהול שיחות עם לקוחות (מזוהים או אנונימיים) מתוך אתר או אפליקציה, עם שמירת היסטוריה מלאה, תגובות קבועות, סגירת שיחה + סקר, והעברת התמלול ל-Dynamics 365 רק בסוף השיחה (או העתק-הדבק מסודר).

## 2. עקרונות מנחים
- פשטות מקסימלית בפיתוח ותחזוקה
- אין Real-time מלא → Polling כל 1.5–2 שניות
- ריבוי שפות מלא (עברית RTL, אנגלית LTR, ערבית, רוסית + קל להוסיף)
- עיצוב פשוט, נקי, אלגנטי ומודרני
- עובד על Cloudflare Pages + Azure / Windows Server
- ניהול גרסאות מסודר + הצגת Ver. / Build / תאריך בכל מסך
- אפס באגים קריטיים (בדיקות יסודיות בכל שלב)
- ניהול מלא לפי Agile/Scrum עם סנכרון מלא ל-Git

## 3. קהל יעד
- נציגי תמיכה (מחשב + מובייל)
- לקוחות באתר / אפליקציה

## 4. דרישות Must Have
- וידג'ט צ'אט לאתר
- לוח נציגים (Inbox)
- זיהוי לקוח / אנונימי
- היסטוריית שיחות
- חיפוש בשיחה
- תגובות קבועות (Canned Responses)
- סגירת שיחה + סקר אוטומטי
- התראות בסיסיות לנציג
- העתק-הדבק מושלם של השיחה (מעוצב)
- תמיכה מלאה ב-RTL + LTR
- Responsive + PWA לנציגים
- API בסיסי לייצוא
- הצגת מספר גרסה, Build ותאריך בכל מסך

## 5. דרישות Should Have
- הערות פנימיות לנציג
- הקצאת נציג / תגיות
- העלאת קבצים
- ייצוא PDF
- חיבור עתידי ליצירת Case ב-Dynamics 365

## 6. לא בגרסה הראשונה
- WebSockets מלא
- בוטים / AI
- WhatsApp / ערוצים נוספים
- סנכרון חי ל-CRM בזמן השיחה
