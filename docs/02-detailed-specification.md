# Chatty – איפיון מפורט
**Ver. 0.1.0 | Build 001 | 03.11.2026**

## 1. משתמשים ותפקידים

| תפקיד     | הרשאות                                      |
|-----------|---------------------------------------------|
| אורח/לקוח | פתיחת שיחה, שליחת הודעות, מילוי סקר         |
| נציג      | כל פעולות השיחה, Canned, סגירה, הערות פנימיות |
| מנהל      | ניהול נציגים, Canned, הגדרות, דוחות בסיסיים |

## 2. מסכים עיקריים

### 2.1 צד לקוח (Widget)
- כפתור צף באתר
- חלון צ'אט (הודעות + שדה הקלדה)
- בחירת שפה
- אפשרות הזדהות (שם / אימייל / מספר לקוח) או אנונימי
- סקר בסוף השיחה
- הצגת גרסה קטנה

### 2.2 צד נציג (Agent Dashboard)
- Inbox (רשימת שיחות פתוחות / ממתינות / סגורות)
- חלון שיחה מפורט
- פאנל Canned Responses
- הערות פנימיות (לא נראות ללקוח)
- כפתור סגירת שיחה + יצירת תמלול
- חיפוש גלובלי ובתוך השיחה
- פרופיל לקוח (אם מזוהה)
- הצגת גרסה קבועה בתחתית כל מסך
- תמיכה מלאה במובייל (Responsive + PWA)

## 3. זרימות מרכזיות

1. **פתיחת שיחה**  
   לקוח פותח וידג'ט → בוחר שפה → מזדהה או נשאר אנונימי → שולח הודעה ראשונה.

2. **טיפול בשיחה**  
   נציג מקבל התראה → נכנס לשיחה → משיב ידנית או באמצעות Canned Response → יכול להוסיף הערה פנימית.

3. **סגירת שיחה**  
   נציג לוחץ "סגור שיחה" → הלקוח מקבל סקר → המערכת יוצרת תמלול מסודר (להעתקה / ייצוא).

4. **העברה ל-CRM**  
   בסוף השיחה בלבד: העתק-הדבק מושלם או (בעתיד) יצירת Case ב-Dynamics 365.

## 4. מבנה נתונים עיקרי

- **Conversations**: id, status, customer_info, language, assigned_agent, created_at, closed_at, tags
- **Messages**: id, conversation_id, sender_type (customer/agent/system), content, created_at, is_internal
- **CannedResponses**: id, title, content, language, category
- **Agents**: id, name, email, role, status
- **Surveys**: id, conversation_id, rating, comment, created_at

## 5. שפות
- עברית (ברירת מחדל, RTL)
- אנגלית (LTR)
- ערבית (RTL)
- רוסית (LTR)
- מנגנון קל להוספת שפות נוספות (קבצי תרגום)

## 6. התראות
- התראה ויזואלית בלוח הנציג על שיחה חדשה / הודעה חדשה
- אפשרות להתראת מייל (שלב מאוחר)

## 7. אבטחה בסיסית
- HTTPS בלבד
- Sanitization של הודעות
- Rate limiting בסיסי
- JWT לנציגים
- הרשאות לפי תפקיד
