## 2. באגים שנמצאו ותוקנו

### BUG-001 – ייבוא @chatty/shared ב-NestJS
**תיאור:** ייבוא מונורפו `@chatty/shared` עלול להיכשל בהרצה ללא בניית package או הגדרות paths מורכבות.  
**חומרה:** בינונית (מונע הרצה קלה).  
**תיקון:** הוחלפו הייבואים לנתיבים יחסיים (`../../../packages/shared/src` וכו').  
**סטטוס:** תוקן.

### BUG-002 – פילטר כפול בלוח נציגים
**תיאור:** ה-API כבר מסנן לפי `status` ו-`q`, והקליינט סינן שוב לפי status (משתנה `filtered`).  
**חומרה:** נמוכה (לא שובר פונקציונליות, רק כפילות).  
**תיקון:** נשאר כרגע (עובד). ניתן לפשט בעתיד להשתמש ישירות ב-`conversations`.  
**סטטוס:** מתועד, לא קריטי.

### BUG-003 – קבצי sed זמניים
**תיאור:** בזמן תיקון אוטומטי נוצרו קבצי `sed*` תחת modules.  
**תיקון:** נמחקו.  
**סטטוס:** תוקן.

## 3. מגבלות ידועות (לא באגים)
- אחסון **in-memory** – נתונים נמחקים בהפעלה מחדש של השרת (מתוכנן להחלפה ב-PostgreSQL).
- אין Auth – כל אחד יכול לגשת ל-API (מתוכנן).
- Polling ולא WebSocket – לפי דרישה (1.5–2 שניות).

## 4. תרחישי בדיקה ידניים מומלצים
1. פתח `/widget` → התחל שיחה (מזוהה + אנונימי) → שלח הודעות.
2. פתח `/agent` → ראה את השיחה ב-Inbox → השב (רגיל + Canned + פנימי).
3. סגור שיחה → ודא שמופיע תמלול → העתק.
4. ב-Widget ודא שמופיע סקר אחרי סגירה.
5. בדוק חיפוש ופילטרים בלוח נציגים.
6. בדוק החלפת שפה ב-Widget.
